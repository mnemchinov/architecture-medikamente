# Реестр инструментов, способов и мер обеспечения конфиденциальности данных

## 1. Идентификация и управление доступом (IAM)

| Инструмент | Назначение | Применение в системе |
|---|---|---|
| Keycloak / Dex | Identity Provider (OAuth 2.0, OpenID Connect) | Единая аутентификация сотрудников и пациентов |
| RBAC | Ролевое управление доступом | Разграничение доступа: пациент, ресепшен, врач, бухгалтер, склад, администратор |
| ABAC | Атрибутивное управление доступом | Тонкая настройка: доступ на основе тегов данных, времени, локации |
| OPA (Open Policy Agent) | Policy-as-Code | Централизованная проверка политик доступа к данным |
| AD/LDAP + синхронизация | Каталог пользователей | Существующий AD синхронизируется с Keycloak |

## 2. Шифрование

| Инструмент | Назначение | Применение |
|---|---|---|
| AES-256-GCM | Шифрование данных at rest | Файловые хранилища, бэкапы |
| PostgreSQL TDE (Transparent Data Encryption) | Прозрачное шифрование БД | Основная БД (медицинские карты, пациенты) |
| ClickHouse encryption | Шифрование данных в ClickHouse | Аналитическая БД |
| TLS 1.3 | Шифрование каналов передачи | Все внешние и внутренние HTTP-каналы |
| mTLS | Взаимная аутентификация сервисов | Service-to-service в Kubernetes |
| HashiCorp Vault | Управление ключами и секретами | Хранение ключей шифрования, сертификатов, ротация |
| cert-manager | Автоматизация сертификатов | Выпуск и обновление TLS-сертификатов в K8s |
| WireGuard / IPsec | Шифрование сетевых каналов | Связь между филиалами |

## 3. Обфускация и маскирование

| Инструмент | Назначение | Применение |
|---|---|---|
| Oracle Data Masking (или аналог Greenmask) | Статическая маскировка | Создание обезличенных копий БД для тестирования |
| Apache NiFi + SSL/TLS + процессоры | Динамическая маскировка в потоках данных | Маскирование PII при передаче в аналитику |
| Faker (Python) / Java Faker | Генерация тестовых данных | Замена реальных данных на синтетические в dev-среде |
| SQL-based masking functions | Маскирование на уровне БД | Динамическое маскирование в PostgreSQL (extension) |

## 4. Аудит и мониторинг

| Инструмент | Назначение | Применение |
|---|---|---|
| Elastic Stack (Elasticsearch, Logstash, Kibana) | Сбор и анализ логов | Централизованное хранение логов доступа |
| Victoria Metrics | Сбор метрик | Метрики производительности, SLA |
| Grafana | Визуализация | Дашборды мониторинга и аудита |
| Audit Log (PostgreSQL audit) | Аудит БД | Логирование всех запросов к БД (pgaudit) |
| Falco / Tracee | Обнаружение НСД на уровне ядра | Мониторинг поведения контейнеров в K8s |
| Wazuh / ELK Security | SIEM | Корреляция событий безопасности |

## 5. Контроль целостности и защита от утечек

| Инструмент | Назначение | Применение |
|---|---|---|
| DLP-система (Solar Dozor / InfoWatch) | Защита от утечек ПДн | Контроль передачи данных за периметр |
| Digital Signature (КЭП/УНЭП) | Электронная подпись | Подписание медкарт, договоров |
| Blockchain / immutable log | Неизменяемый журнал | Audit trail для критических операций (QIWI Blockchain, Hyperledger) |

## 6. Инфраструктурные средства

| Инструмент | Назначение | Применение |
|---|---|---|
| Kubernetes Network Policies | Сетевая сегментация | Микросегментация между микросервисами |
| Istio / Linkerd | Service Mesh | mTLS, авторизация, трассировка между сервисами |
| Trivy / Aqua Security | Сканирование уязвимостей | Образы контейнеров, IaC |
| Velero | Резервное копирование K8s | Бэкапы etcd, PVC |
| pgBackRest | Резервное копирование Postgres | Point-in-time recovery, шифрование бэкапов |

## 7. Организационные меры

| Мера | Описание |
|---|---|
| Назначение ответственного за ПДн | Согласно 152-ФЗ ст. 18.1 |
| Разработка политики обработки ПДн | Документ, регламентирующий сбор, хранение, передачу и удаление ПДн |
| Получение согласий на обработку ПДн | Электронная форма на портале, бумажная — в офисе |
| Уведомление РКН | Подача уведомления о начале обработки ПДн |
| Классификация и тегирование | Внедрение схемы тегирования данных (см. tagging.md) |
| Обучение персонала | Периодические тренинги по работе с ПДн и информационной безопасности |
