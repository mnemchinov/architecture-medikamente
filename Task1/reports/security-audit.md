# Аудит мер по обеспечению безопасности данных

## Текущие меры защиты (As-Is)

| Мера защиты | Где применяется | Эффективность |
|---|---|---|
| Доменная аутентификация (AD) | Доступ к ПК и файловому серверу | Средняя. Нет MFA, единая точка входа при компрометации |
| Active Directory — разграничение прав | Файловый сервер, Exchange | Низкая. Права доступа не сегментированы по ролям |
| Локальная сеть (TCP/IP) — физическая изоляция | Все системы | Высокая (в пределах одного здания), но не защищает от инсайдеров |
| Парольная защита 1С | 1С:Бухгалтерия, 1С:Торговля | Низкая. Файловый режим — БД в виде файлов, доступных через файловый сервер |

## Оценка по категориям безопасности (CIA)

### Конфиденциальность
- **Оценка: Критический уровень риска**
- Файлы пациентов (медицинские карты, сканы, Excel) лежат в открытом доступе на файловом сервере
- 1С работает в файловом режиме — база данных доступна через общую папку
- Отсутствует шифрование данных at rest и in transit (кроме базовой сетевой изоляции)
- Нет сегментации доступа по ролям (врач может видеть данные другого врача, администратор — данные врача)

### Целостность
- **Оценка: Высокий уровень риска**
- Excel-файлы не защищены от изменений — любой сотрудник с доступом может изменить данные без отслеживания
- Файловый режим 1С не гарантирует целостность при конкурентном доступе
- Отсутствует журнал аудита изменений
- Нет контроля версий документов

### Доступность
- **Оценка: Средний уровень риска**
- Единый физический сервер — единая точка отказа
- Нет резервирования (RAID, бэкапы — не обнаружены)
- Нет плана восстановления после сбоев (DRP)
- Зависимость от одного администратора сети
