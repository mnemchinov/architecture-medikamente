# Список проблемных зон

## 1. Управление доступом
- [P1] Нет сегментации прав доступа по ролям (AD-группы не настроены)
- [P2] Отсутствует MFA для доступа к системам
- [P3] Файловый сервер доступен всем сотрудникам без разграничения
- [P4] Нет политики наименьших привилегий (least privilege)

## 2. Шифрование данных
- [P5] Данные на файловом сервере не шифруются (at rest)
- [P6] Каналы передачи данных между системами не шифруются (in transit)
- [P7] 1С в файловом режиме — БД не защищена шифрованием
- [P8] Ноутбуки/ПК сотрудников — нет шифрования дисков

## 3. Аудит и мониторинг
- [P9] Отсутствует журналирование доступа к файлам пациентов
- [P10] Нет системы мониторинга событий безопасности (SIEM)
- [P11] Нет механизма обнаружения нетипичных действий пользователей
- [P12] Нет алертинга при инцидентах

## 4. Обработка персональных данных
- [P13] Нет формализованного согласия на обработку ПДн
- [P14] Не назначен ответственный за обработку ПДн
- [P15] Нет политики обработки ПДн
- [P16] Нет уведомления РКН о начале обработки

## 5. Жизненный цикл данных
- [P17] Отсутствуют сроки хранения данных
- [P18] Нет процедуры удаления данных по истечении срока
- [P19] Нет процедуры обработки запросов субъектов ПДн (отзыв согласия, удаление)
- [P20] Нет механизма Data Minimization (сбор только необходимых данных)

## 6. Инфраструктура
- [P21] Единый физический сервер — единая точка отказа
- [P22] Файловый режим 1С — риск повреждения БД при конкурентном доступе
- [P23] Отсутствует резервное копирование (или не обнаружено)
- [P24] Нет плана восстановления после сбоев (DRP/BCP)
- [P25] Физический сервер находится в том же здании, что и офис (риск физического доступа)

## 7. Интеграции и обмен данными
- [P26] Взаимодействие с лабораторией — неформальный обмен файлами (email, флешки)
- [P27] Передача данных между 1С-системами через OLE — нет контроля целостности
- [P28] API-контракты с лабораторией не определены
- [P29] Обмен данными с внешними контрагентами — без шифрования и ЭЦП

## 8. Организационные
- [P30] Малая IT-команда (3 чел.) на 35+ сотрудников
- [P31] Отсутствие DevSecOps-практик
- [P32] Нет регулярного обучения сотрудников信息安全 (информационной безопасности)
- [P33] Нет классификации данных (все данные хранятся вперемешку)
