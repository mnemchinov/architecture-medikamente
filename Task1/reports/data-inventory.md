# Инвентаризация конфиденциальных данных

## 1. Персональные данные (ПДн) — субъекты: пациенты

| Категория данных | Примеры | Формат хранения | Где хранится | 152-ФЗ категория |
|---|---|---|---|---|
| Идентификационные данные | ФИО, дата рождения, пол | Excel, сканы договоров | Файловый сервер (Patients.xlsx, договоры PDF) | Общие ПДн |
| Контактные данные | Номер телефона, email, адрес прописки | Excel, сканы | Файловый сервер | Общие ПДн |
| Социальные данные | Место работы/учёбы | Расширенная форма (бумага/скан) | Файловый сервер | Общие ПДн |
| Медицинские данные | Хронические заболевания, диагнозы, назначения | Медицинская карта (PDF/JPG) | Файловый сервер (папка пациента) | Специальные ПДн |
| Результаты анализов | Лабораторные исследования | Excel (RegistryByDate), PDF | Файловый сервер | Специальные ПДн |

## 2. Финансовые данные

| Категория данных | Примеры | Формат хранения | Где хранится |
|---|---|---|---|
| Платёжные реквизиты | Сумма, услуга, дата, способ оплаты | 1С:Бухгалтерия (файловый режим), Excel | 1С + Файловый сервер |
| Выручка и отчётность | P&L, ABC-анализ | Excel | Файловый сервер |
| Зарплата и налоги | Начисления сотрудникам, НДФЛ, взносы | 1С:Бухгалтерия (файловый режим) | 1С |
| Кадровый учёт | Трудовые договоры, приказы | 1С:Бухгалтерия, сканы | 1С + Файловый сервер |

## 3. Товарно-материальные ценности (ТМЦ)

| Категория данных | Примеры | Формат хранения | Где хранится |
|---|---|---|---|
| Номенклатура | Медикаменты, оборудование, расходники | 1С:Торговля и склад (файловый режим) | 1С:Торговля |
| Закупки | Поставщики, цены, даты поставок | 1С:Торговля и склад | 1С:Торговля |
| Остатки | Количество на складе | 1С:Торговля и склад | 1С:Торговля |

## 4. Учётные и служебные данные

| Категория данных | Примеры | Формат хранения | Где хранится |
|---|---|---|---|
| Учётные записи | Логины, пароли (AD) | Active Directory | Windows Server 2022 |
| Журналы записи | Расписание приёма, ФИО пациента, специалист | Excel | Файловый сервер (Journal-Doctor-FIO.xlsx) |
| Договоры | Клиентские контракты | Сканы PDF | Файловый сервер |
| Переписка | Внутренняя почта | Exchange | Exchange Mail Server |

## 5. Данные, не учтённые в системах (выявлены при анализе)

- **Метаданные о доступе**: отсутствуют журналы, кто и когда обращался к файлам пациентов
- **Согласия на обработку ПДн**: не выявлено формализованного процесса получения и хранения согласий
- **Политики удаления данных**: нет регламентов сроков хранения и уничтожения
- **История изменений**: в Excel и 1С в файловом режиме отсутствует полный аудит изменений
- **Данные о состоянии здоровья в свободной форме**: врачи могут вносить заметки в любом формате без контроля
