## Методы защиты: детальное описание

### Шифрование
- **At rest**: AES-256-GCM для БД (Postgres TDE, ClickHouse), файлов (EFS/LUKS), бэкапов
- **In transit**: TLS 1.3 для всех HTTP-каналов, mTLS для service-to-service, WireGuard для филиалов
- **Ключи**: HashiCorp Vault / External Secrets Operator + автоматическая ротация

### Обфускация
- **Токенизация**: замена ПДн (ФИО, телефон, email) на токены при передаче в аналитические системы
- **Скремблирование**: искажение символов в тестовых средах (например, «Иван Иванов» → «Крдэ Лвлсж»)

### Маскирование
- **Динамическое**: сотрудник видит только данные, необходимые для его роли (например, кассир видит только последние 4 цифры паспорта)
- **Статическое**: создание обезличенной копии БД для разработки и тестирования

### Обезличивание
- **Псевдонимизация**: замена идентификаторов на псевдонимы для BI-аналитики (сохраняется связность, но без прямой идентификации)
- **Анонимизация**: необратимое удаление идентификаторов для ML-моделей и публичных отчётов

### Тегирование
- Автоматическая маркировка данных при вводе: тег категории (PII, MEDICAL, FINANCIAL), уровень чувствительности, срок хранения
- Блокировка выгрузки немаркированных данных
